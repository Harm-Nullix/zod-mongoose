# Start Here

Define a Zod schema once, convert it to a Mongoose schema, and use the result with a normal Mongoose model. This example runs without a database connection so you can check the setup first.

## Install the packages

Use Node.js 24 or newer. Install `zod` and Mongoose for a backend application. The package supports Mongoose 9 and Zod 4; `zod/v4` is the **import path**, not the package name to install.

::code-group
```bash [pnpm]
pnpm add @nullix/zod-mongoose zod@^4 mongoose@^9
```

```bash [npm]
npm install @nullix/zod-mongoose zod@^4 mongoose@^9
```

```bash [yarn]
yarn add @nullix/zod-mongoose zod@^4 mongoose@^9
```

```bash [bun]
bun add @nullix/zod-mongoose zod@^4 mongoose@^9
```
::

Mongoose is an optional peer dependency if you only define shared Zod schemas in the browser. You need it on the server to call `toMongooseSchema()`.

## Create and validate a model

```ts [first-model.ts]
import mongoose from 'mongoose';
import {z} from 'zod/v4';
import {toMongooseSchema} from '@nullix/zod-mongoose';

const UserZodSchema = z.object({
  name: z.string().min(2),
  email: z.email(),
});

const UserModel = mongoose.model('User', toMongooseSchema(UserZodSchema));
const user = new UserModel({name: 'Ada', email: 'ada@example.com'});

await user.validate();
console.log(user._id); // Mongoose generated an ObjectId
```

`toMongooseSchema()` returns a Mongoose `Schema`, so you can use normal Mongoose models and queries. `validate()` checks the document in memory. Connect to MongoDB before calling database methods such as `create()` or `find()`.

## Save a document

Once MongoDB is running, add this after the model definition above. Set `MONGODB_URI` for your own database; the fallback uses a local MongoDB instance.

```ts
await mongoose.connect(process.env.MONGODB_URI ?? 'mongodb://127.0.0.1:27017/zod-mongoose-example');
try {
  const saved = await UserModel.create({name: 'Ada', email: 'ada@example.com'});
  console.log(saved._id);
} finally {
  await mongoose.disconnect();
}
```
